# מתכונים: מה כבר יש במנוע, ודפוסי אינטראקציה למדעים

נלווה ל־`SKILL.md`. לפני שבונים משהו חדש — לבדוק כאן אם כבר יש כלי. כל הנתיבים יחסית לשורש המאגר.

## א. המנוע (`tools/deck/`)

| קובץ | מה |
|---|---|
| `deck.js` | ניווט, צעדים, טיימרים, הערות (S), דף השיעור (G), כל השקופיות (O), מעבר לשקופית לפי `#מספר` |
| `deck.css` + `science.css` | עיצוב משותף לשיעורים 7–8. **שינוי כאן משפיע על כל השיעורים** — עדיף `D.css` של השיעור |
| `kit.py` | `Deck` (הרכבת העמוד) וכלי ציור SVG |
| `anim7.js` | מנוע ההנפשות בפסים ובנקודות (מצבים `f2`, `ch4`, `h2o`) |
| `anim_h2.js` + `anim_h2.css` | ההנפשה „שני אטומים משתפים” משיעור 6 (עננים), כמו שהיא |
| `../lab04_fair.js` | ההמחשה „ניסוי הוגן” (מעבדה 04): טבלה שהיא פקד, מודל אחד ← תוויות, מונה, ציור, מסקנה |

**שקופית:** `D.add(body, notes, title, ch, sec='', cls='s', mins=1)`.
`ch` = צבע החלק: `open` (פתיחה, חזרה, סגירה), `a`, `b`, `ext`. `cls`: `s s--center` (שקופית מרכזית/דרמטית), `s s--sec` (מחיצה), `s s--cover` (שער).
השקופית הפעילה — `.s.on`. ב־CSS: `var(--ac)` / `rgba(var(--ac-rgb),…)` = צבע החלק.

**צעדים** (לחיצה = הצעד הבא, לפי סדר במסמך):
- `.frag` — מקבל `.show` כשנחשף. כל רכיב יכול להיות frag (גם קבוצה בתוך SVG).
- `.mcq` — שאלה אמריקאית; `data-ok` על התשובה הנכונה; מקבל `.done` כשנחשפת.
- `data-count="9"` בתוך frag — המספר נספר מ־0 כשנחשף.
- `.timer data-sec="300"` — טיימר (T).
- **`data-hook="שם"`** על השקופית + `window.DeckHooks['שם']={enter(sl,back), next(sl), prev(sl), leave(sl)}` —
  השקופית לוקחת את מקש ההתקדמות כל עוד יש לה מה לעשות (`next` מחזיר `true` = „טיפלתי”). זה הבסיס לאינטראקציה בשלבים.
- לחיצה על `button`, `a`, `input`, `.timer` לא מקדמת שקופית — אינטראקציה בלחיצה בונים על `<button>`.

**CSS ו־JS של שיעור:** `D.css = '''…'''` (אחרי science.css), `D.js = …` (אחרי המנוע). שניהם במחולל.

## ב. כלי הציור (`kit.py`)

| פונקציה | מה מצייר |
|---|---|
| `atom(sym, n, r, inner=None, label=None, lay=None)` | אטום: גרעין, פס חיצוני ו־n אלקטרונים במודל הזוגות; `inner` = פס פנימי; `lay={'r':1,'t':2,…}` = פריסה ידנית |
| `mol2(a, b, shared, lone_a, lone_b, ra, rb, w)` | שני אטומים בשורה עם זוגות משותפים |
| `bent(center, …)` | מולקולה כפופה עם שני מימנים (מים) |
| `star(center, subs, …)` | אטום מרכזי ושכנים (CH₄, CCl₄) |
| `model(atoms, bonds, …)` | מודל כדורי בצבעי הספר (עמ׳ 29) |
| `ptable(…)`, `tile(…)`, `fulltable(…)` | הטבלה המחזורית |
| `F('H₂O')` | נוסחה (כיוון LTR, מודגש) |

**מחלקות על האלקטרונים** (מ־14.11) — כדי שאפשר יהיה להדגיש ולהנפיש בלי לשנות את הציור:
`el` כל אלקטרון · `s1` בודד · `p2` חלק מזוג · `sh` בזוג משותף · קבוצות: `e-in` (פס פנימי), `e-out` (פס חיצוני), `e-sh` (זוג משותף ב־`mol2`).

## ג. מתכונים שכבר עובדים

**1. אלקטרונים חיים** (שיעור 7, `D.css`): כל `.el` בשקופית הפעילה זז 1–2 פיקסלים בתנועה לא סדירה (שלוש keyframes, משכים שונים), עם `transform-box:fill-box`.
לא מסלול — תזוזה קטנה בתוך האזור. נעצר ב־`prefers-reduced-motion`.

**2. הדגשה בזמן חשיפה** (שיעור 7, שקופיות 9 ו־14): מחלקה על ה־frag, ו־`:has` ב־CSS:
```css
.s:has(.hl-in.show):not(:has(.hl-out.show)) .e-in .el { animation: jgh 3.1s infinite, hl 1.3s infinite }   /* גדל וזוהר — בלי לשנות צבע */
.s:has(.hl-in.show):not(:has(.hl-out.show)) .e-out .el { opacity:.35 }
```
ה־`:not(:has(...הבא))` מעביר את ההדגשה לצעד האחרון שנחשף. להדגשה חדשה: מחלקה חדשה על ה־frag + קבוצה/מחלקה בציור.

**3. הנפשת תהליך** (`anim7.js`). מאפיינים על ה־div: `data-wait="mcq"` (מחכה לניחוש), `data-vmin="500"` (מתחת לרוחב הזה — פריסה אנכית; ברירת מחדל 700). `atom(sym, R, p0, p1, tA, tB, sites)` — אטום שזז מ־p0 ל־p1 בין tA ל־tB; `sites=[[זווית, 1|2], …]`.
`bond(a, sa, b, sb, t0)` — בזמן t0 שני הבודדים הופכים לזוג משותף. כיתובים: `once('c2', ()=>say('…'))` לפי זמן. מצב חדש = ענף `else if(mode==='…')` ב־`build` ובכיתובים, ושקופית עם `<div class="anim a7" data-mode="…">`.
הכיתובים — **משפטים מהשקופית שלפני**, מילה במילה. כולל: ענן זוהר, זוהר משותף בקשר, שובל קצר לבודדים, הבזק בקשר, פריסה אנכית בטלפון (`V`).

**2א. הדגשה בזמן חשיפה — בלי אלקטרונים** (מעבדה 04, 15.11). אותו מתכון על כל ציור: קבוצה בציור (`<g class="xg">`), מחלקה על ה־frag (`hl-x`),
ו־`.s:has(.hl-x.show) .xy .xg{animation:glx …}` (זוהר בצבע של המושג — זהב למשפיע, תכלת למושפע, ירוק לזהה, אדום לשונה). אפשר גם להזיז: הכפתור X מסתובב והמד Y עולה ויורד איתו (`transform-box:view-box` ו־`transform-origin` בפיקסלים של ה־viewBox).
חלק שמופיע רק בצעד — `opacity:0` ו־`.s:has(.hl-….show) … {opacity:1}` (מנעולים, „?”, תוויות, קו השערה על גרף). קו שנמחק — `pathLength="1"` ו־`stroke-dashoffset` מ־1 ל־0.
משפט שגדל באותו מקום (טענה ← טענה + נימוק): הנימוק הוא frag בתוך המשפט, עם `:not(.show){display:none}` — כדי שהפיסוק לא יישאר תלוי.

**4. הנפשה משיעור קודם כתזכורת** (`anim_h2.js`): מעתיקים את הסקריפט כמו שהוא, מחליפים `closest('.slide')` ב־`closest('.s')`, ומכניסים את ה־CSS שלו ב־`<style>` בתוך השקופית.
שמות מחלקות קצרים (`g`, `r`) מתנגשים במנוע — לשנות (`cg`, `cr`).

## ה. בדיקות (סקריפטים שעבדו ב־14.11)

- **צעד אחרי צעד:** פותחים `file://…#N`, לוחצים ArrowLeft ומצלמים אחרי כל לחיצה.
- **השקופית במצב הסופי:** פותחים `#N+1` ולוחצים ArrowRight — השקופית N נפתחת עם כל הצעדים גלויים.
- **הנפשה:** צילום ב־3–4 זמנים (למשל 2, 6, 9, 13 שניות) + איסוף `pageerror`.
- **בדיקה שהתנועה רצה:** `getComputedStyle(el).animationName` ו־`transform` על `.s.on svg .el`.
- **גרסת התלמידים:** `python3 tools/build_student.py <תיקייה>` ו־`PW=$(npm root -g)/playwright node tools/qa/phone.js <תיקייה> <צילומים> lesson-07`.
