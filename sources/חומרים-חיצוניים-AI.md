# חומרים קיימים ברשת — מה שווה לקחת (22.11.2026)

נאסף לבקשת יניב: מצגות ומערכי שיעור על AI. ✅ = נקרא ישירות. ◻ = רק תקציר חיפוש, לא נפתח.

| חומר | מה יש בו | לאן אצלנו |
|---|---|---|
| ✅ משרד החינוך, „מידע ונתונים", חשיבה ביקורתית והערכת מידע ([דף](https://pop.education.gov.il/tchumey_daat/data-analysis/high-school/teaching-materials/critical-thinking-info-evaluation/)) | מצגות: חשיבה ביקורתית, הערכת אתרים (**4 אמות מידה: עדכניות, אמינות, דיוק, אובייקטיביות**), גרפים מטעים, דיפ-פייק (4 שיעורים) | שיעור המקורות (AI 5) |
| ✅ משרד החינוך, מדריך „כך תתמודדו עם הזיות" (אייל מרקוס) | סיבות להזיות, וטכניקות: פרומפט ברור, „השתמש רק במסמך המצורף" | שיעור הפרומפט (AI 4) |
| ◻ LLMs Unplugged / CMU sticky notes / Act Out an LLM | **בלי מחשב:** טבלת מילים מודפסת וקובייה — הכיתה „מייצרת" משפט מילה אחרי מילה | תרגול מוחשי לשיעור 1–2 |
| ◻ Experience AI (Raspberry Pi + Google DeepMind), שיעור LLMs לגילאי 11–14 | חיפוש מול צ׳אט, ו**„האם צ׳אט מתאים למשימה הזו?"** | משימת מיון: מתי כן AI ומתי לא (AI 4–5) |
| ◻ Common Sense Education, „Designed to Feel Human" (ט–יב, 2026) | איך צ׳אטים בנויים להיראות כאילו הם מבינים אותך | שיעור „התוכנה למדה מאנשים" (AI 3) |
| ◻ British Council, מסגרת אוריינות AI לחינוך מיוחד | התאמות לתלמידים עם צרכים מיוחדים | רקע למורה |
